    Preview

    This preview carries no styling of its own, so text appears in whatever font your browser falls back to. The finished document takes its appearance from wherever it ends up — Brightspace or a Word document you paste it into — so this may not be exactly how the content will look once it is placed.

    To add the syllabus to Brightspace:

    1. Choose Copy formatted, just below.
    2. In your course, choose Upload / Create > Create a file.
    3. Provide a title, such as "Course Syllabus"
    4. If desired, open the Select a Document Template menu to choose a styled template.
    5. Paste into the editor, then save.

    Copy formatted puts the finished layout on the clipboard, ready to paste into Brightspace or Word.

    Show HTML source code

    If formatting is lost when you paste, use Copy HTML instead and paste into the editor's source code view.
